type: ai-coding-rule
appliesTo:
  - gateway-backend-communication

Ask, Auto, Act, Presence, Voice, Command, Chat execution, workflows, and
schedules must project one Main-owned Objective Core. Do not create a Renderer
planner, a second executor, a second grant store, or synthetic progress.

Autonomous first use applies only to capabilities explicitly declared eligible
in the frozen registry and only after Main resolves a compiled-in or registered
exact scope. It cannot authorize arbitrary executable paths, argv, shell,
PowerShell, environment variables, unrestricted filesystem paths, credentials,
finance, privilege, security changes, or unrecoverable actions.

Automatic memory must be Main-owned, bounded, atomic, and inspectable. Never
persist microphone audio, raw transcripts, credentials, secrets, arbitrary file
content, raw provider prompts, or raw Audit as memory.

The business-site journey must write only inside the selected approved
workspace, validate real output, and report credential-dependent deployment as
unavailable when it cannot produce a real destination. Provider output remains
untrusted proposal data and never executes directly.
