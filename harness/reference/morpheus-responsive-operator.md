# Responsive operator boundaries

Provider output caps are safety/efficiency limits, not currency guarantees.
OpenClaw conversation traffic is separate from the typed Morpheus planner; do
not claim a Core limit covers third-party tool loops or reconciles a provider bill.
Reserve a bounded allowance before each request, including retries. Never retry
an ambiguous network failure automatically: a request might already be billable.
Only numeric provider usage metadata may be audited, never raw response data.

Speech cancellation invalidates asynchronous preflight and aborts active HTTP.
Providers may still bill work already generated. Audio remains ephemeral.
Presentation must reflect listening and speech even after an objective completes.
No repeated TTS request merely because objective metadata changed.
