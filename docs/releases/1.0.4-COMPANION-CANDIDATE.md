## Real blockers and limits

- Packaged selected-voice preview returned the `authentication` failure category
  and completed with **Windows fallback**, not neural speech. A valid TTS endpoint
  credential is needed, configured locally. No keys were printed or committed.
- Native recognition loads but the default input device cannot be opened. A later
  local-helper initialization retry also failed. A working default input and
  repeatable real-device wake/command tests are required. This does not establish
  that the microphone is physically absent; the Windows recognition input path
  failed. Present AudioEndpoint enumeration listed only Realtek digital output
  and the monitor output, with no microphone endpoint listed.
- One follow-up command is supported. Continuous full-duplex conversation, voice
  personality adaptation and reliable interruption across a whole spoken task
  have NOT been certified by this work.
- An exploratory all-product E2E run was interrupted before completion. Three
  attachment/history failures reproduce on the untouched `9908e7d` checkpoint:
  spreadsheet transcript restoration, delayed transcript retry after session
  switching, and heartbeat-only session startup. They remain pre-existing issues,
  not resolved by this companion change. The separate HTML-preview check is
  intermittent; it passed on baseline and subsequent current-build repeats.
  Do not call the whole-product E2E suite green.
- Signing, clean-machine installation, live usage/cost reconciliation and owner
  acceptance remain in `PUBLIC-RELEASE-GATES.md`.
- Source changes remain uncommitted on `codex/morpheus-windows-production-candidate`
  based on `9908e7d5c15f3e936d5fc7a34b8f8cc3e9377418`. No push was performed.
