# Morpheus 1.0.5 visual review candidate

Prepared for Larry's private product review. Not public-release approved.

## Scope

This is a focused presentation update on top of the uncommitted 1.0.4 companion
work. It does not change execution authority, grants, pricing, provider selection,
microphone opt-in or OpenClaw integration.

- Calmer luminous sphere with fewer competing filaments and stationary outer
  reference marks. Listening intensity still comes from real microphone energy.
- Opaque greeting with short staggered text, responsive typography and a gentle
  handoff. Buttons remain usable without waiting for the introduction.
- Inline greeting speech/fallback status removes a duplicate floating speech HUD.
  Active input, follow-up and error indicators are not hidden.
- Quick Command entry/exit, consistent control feedback, keyboard focus outlines
  and reduced-motion handling. No API calls are made to generate animation.
- Full-window animated blur removed from boot/activation transitions.

## Known limitations carried forward

The 1.0.4 live neural preview failed authentication and used Windows fallback.
The default Windows recognition input could not be opened. This visual update
does not fix credentials or hardware, and no natural hands-free quality claim is
made. Users need compatible provider access and a working default microphone.

The broader Chat attachment/history failures reproduced on untouched `9908e7d`
are documented in `1.0.4-COMPANION-CANDIDATE.md`; this is not a claim that all
product E2E tests pass. Signing, clean-machine installation and live provider/cost
acceptance remain in `PUBLIC-RELEASE-GATES.md`.

## Review journey

1. Install the newly versioned candidate and keep existing application data.
2. Open Morpheus. Inspect the greeting, sphere and transition into the workspace.
   Reopen greeting through Companion if it was already dismissed.
3. Enter "Show system information". Inspect the real result and Activity record.
4. Open Presence / Quick Command, type the same command, then expand to workspace.
5. Inspect Voice settings. Use the explicit preview and microphone check; Windows
   fallback is not the neural voice. Background microphone capture is opt-in.
6. Try Keep me in the tray, then restore Morpheus using its tray menu.

Share feedback on introduction, clarity, motion and command/result flow separately
from voice quality or missing capabilities. No profile reset is needed for review.
