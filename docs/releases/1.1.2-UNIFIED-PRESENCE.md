# Morpheus 1.1.2 Unified Presence Candidate

Morpheus 1.1.2 closes the visible split between OpenClaw Chat and the Morpheus
operator runtime. It does not replace OpenClaw. It makes Chat participate in
the same interaction routing, Objective Core, voice presence and living Signal
used by Command Center and Quick Command.

## User-visible correction

- Chat always shows a prominent Morpheus Signal and truthful live state.
- Ask, Auto and Act remain one composer-level choice.
- OpenClaw conversation, tool execution and permission waits animate from real
  ACP session events.
- Actionable text can enter Objective Core without navigating away from Chat.
- Chat-origin objectives expose their real status, result summary and stop
  control beside the Signal.
- Attachments and explicitly targeted agents continue through OpenClaw Chat.
- Reduced-motion behavior remains respected.

## Runtime boundary

The Renderer projects Main-owned Objective Core and Voice state plus ordered
ACP timeline state. It does not manufacture progress, tool calls, permissions
or completion. Native authority, scoped permission evaluation and audit
persistence remain in Electron Main.
