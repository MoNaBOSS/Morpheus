## 8. Packaged smoke — 14 points

1. Morpheus identity visible
2. No ClawX in normal UI
3. Boot reaches READY
4. `/` opens Command Center
5. `/chat` connects to OpenClaw
6. System report runs automatically under Balanced
7. Notepad asks first time
8. "Allow for this session" prevents a second prompt for the same scope
9. Revoking the session grant makes the next launch ask again
10. Persistent exact-scope grant survives restart
11. File creation respects the approved root
12. Timeline, artifacts and audit reflect real operations
13. Update checks do not target ClawX
14. No duplicate processes, startup loops or fatal console errors

## 9. Known acceptable limitations

- **Authenticode signing unavailable locally.** Production signing is CI-dependent
  via SignPath; `electron-builder.yml` carries no certificate. Reported truthfully,
  never faked.
- **Deterministic interpreter** handles a small phrase set. Temporary by design,
  behind the permanent `ExecutionPlan` contract.
- **Windows only.** Other platforms are architectural targets, not deliverables.
