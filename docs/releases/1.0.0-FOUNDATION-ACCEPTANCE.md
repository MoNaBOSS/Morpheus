# Morpheus Windows 1.0 Foundation — Acceptance

This is a usable Windows foundation, not a claim that public production 1.0 has
no remaining commercial or distribution work. A criterion passes only through a
real end-to-end implementation; contracts, mock providers and placeholder pages
do not count.

Release candidate version: `1.0.0`

Verification status: source implementation complete; full validation, packaging,
and normal-production smoke verification in progress.

## Core experience

- Voice, Command Center, Quick Command and Chat execution mode submit to one
  Main-owned objective pipeline.
- Real runtime states drive the interface from READY through completion/error.
- A configured real provider can produce a validated multi-step plan.
- Deterministic fallback is labelled honestly and remains useful offline.
- Structured observation can complete or produce a bounded continuation plan.
- Cancellation and correction work without hidden loops.

## Trust and execution

- Plan trust is evaluated once and exact grants are reused.
- A continuation asks only for genuinely new boundaries.
- Trusted workspace operations do not prompt file by file.
- Critical, financial, credential, privilege, destructive, security and
  materially broader boundaries retain appropriate interruption.
- Providers, Agent Profiles, workflows, schedules and Renderer state cannot
  create grants or execute capabilities directly.
- Audit degradation blocks unsafe execution.

## Product systems

- Workspaces are canonical Main-owned roots selected through trusted UI.
- Context supports meaningful follow-up without unbounded transcript injection.
- General, Research and Developer Agent Profiles are editable and usable.
- Workflows can be created, validated, run and scheduled.
- Schedules can be created, edited, enabled, disabled, run now and inspected.
- Artifacts retain plan/step lineage and can be safely opened or revealed.
- Activity explains user-facing work; Audit retains exact authorization evidence.

## Voice and Windows behavior

- Push-to-talk captures real microphone audio and shows visible state.
- At least one real transcription provider works when configured.
- Text-to-speech works and can be disabled/interrupted.
- Global Quick Command and voice shortcuts work from another Windows app.
- Tray/background, single-instance, startup option, pause and graceful shutdown
  behavior are verified.

## Interface

- The default screen visibly feels like an operating AI system, not chat with a
  sidebar or a generic admin dashboard.
- Current objective, system state, voice control, plan, execution, profile,
  trust and artifacts are visible at 1280x800.
- Matrix influence is restrained and stateful.
- Reduced motion, keyboard navigation, focus, DPI and common high-resolution
  layouts are checked.
- UI is visually inspected during the campaign against an accepted concept.

## Preservation and release

- OpenClaw Gateway and ordinary Chat remain functional.
- Models, Agents, Channels, Skills, Cron and Settings remain reachable.
- Security review covers CSP, sandbox, broad Gateway RPC, file, external-open and
  webview boundaries; remaining accepted risk is documented.
- Typecheck, lint, Morpheus units, E2E, comms, harness, build and Windows package
  checks run.
- A normal-production packaged smoke covers the unified objective flow, voice,
  planning, trust reuse, replan, artifacts, Chat, restart and cleanup.
- The installer identity is Morpheus and signing status is reported truthfully.
