# Morpheus 1.0.1 — Fluid arrival

## Scope

- Visible personalized welcome after boot for existing profiles.
- Full workspace or explicit tray choice; no automatic microphone enablement.
- Companion header shortcut reopens welcome without resetting configuration.
- Larger original filament Signal, stronger Matrix boot field, shorter smooth
  setup and page transitions, reduced-motion support.
- Activation final screen waits for a decision instead of disappearing.
- Speech stop/supersession settles playback and suppresses stale provider audio.
- Main rejects tray handoff if no associated live tray exists.

No planner, execution permission, OpenClaw or provider credential authority is
changed. This is a Windows experience update, not a claim that all long-term
Morpheus capabilities are implemented. Local signing remains CI-dependent.
