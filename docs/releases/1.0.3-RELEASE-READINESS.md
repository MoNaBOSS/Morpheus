# Morpheus 1.0.3: release readiness candidate

Status: private verification candidate, **not approved for public release**.
Runtime source: `681e1617c80841a273f1e89f2b12ee960d4f000c`.
Branch: `codex/morpheus-windows-production-candidate`.

## Changes

- Main records safe neural-speech failure categories before publishing them.
  Settings and the speaking indicator explain Windows fallback and how to recover.
  HTTP 401 is authentication failure, not evidence of quota exhaustion.
- Voice settings are persisted atomically before replacing in-memory settings.
- Electron 41.10.3 and affected runtime/build dependencies replace versions with
  published advisories. SheetJS uses the maintainer's 0.20.3 distribution.
- The bundled image parser has a locked local patch for non-progressing ICNS,
  HEIF and JXL loops. Both build paths stamp a dependency revision so Main also
  refreshes older installed managed plugin mirrors with the same upstream version.
- A full-tree dependency release check verifies the patch, reports its two exact
  locally remediated advisories explicitly, and rejects unhandled findings.
- Release CI runs full units, the communication harness and focused Electron
  journeys, requires Morpheus-owned signing configuration for stable tags and
  creates drafts rather than automatically publishing. No inherited signing ID.
- Test fixtures now model Windows/POSIX paths correctly. Bounded unit parallelism
  prevents resource-contention timeouts without weakening product assertions.
- The above-fold test waits for the existing 240 ms route entrance to settle;
  the same 1280x800 geometry requirement remains enforced.

The existing Signal, greeting, tray handoff, voice controls, Objective Core,
permissions, artifacts and OpenClaw interfaces are preserved. No pricing screens,
new commercial promises, profile resets or public release were introduced.

## Public-release limitations

The [public release gates](PUBLIC-RELEASE-GATES.md) remain authoritative. In
particular, valid live STT/TTS access and real microphone quality, reconciled
provider spending (including independent OpenClaw Chat), publisher signing,
clean Windows installation/upgrade/uninstallation and owner-approved privacy/
support arrangements have not been substituted with automated fixtures.

Core generation limits are not a currency cap and do not cover other clients of
the same API key. The EUR80 website charge is not explained by the available
local evidence. A provider-side usage export is still needed. No broad paid
website test was run in this release check. Automatic updates remain disabled.
