# Morpheus Operator Private Alpha Acceptance

The private alpha is accepted only when these real packaged journeys work.

## One operator

- Presence, Command Center, Voice, Quick Command, Chat Act, workflows, and
  schedules submit actionable objectives to the same Objective Core.
- Ask, Auto, and Act are understandable and do not create separate engines.
- Auto distinguishes an ordinary question from a clear work objective.
- Chat remains fully functional through OpenClaw and is visually secondary.

## Background companion

- Setup asks what to call the user and offers tray startup, wake phrase,
  spoken responses, and personality controls.
- Tray, global shortcut, and push-to-talk work without navigating to Chat.
- Ambient capture is opt-in, visibly armed, immediately mutable, and truthful
  about local versus provider-backed detection.
- Unclear speech requests one repeat; a valid transcript creates one Mission.
- Missing voice configuration links directly to provider setup, while an
  unclear recording remains a simple retry rather than a false provider error.
- Activation and Command Center report provider readiness only for a
  credentialed planner-compatible account; Chat-only accounts remain usable but
  are not presented as Objective Core ready.

## Autonomy and memory

- Fresh setup recommends Autonomous and explains protected boundaries.
- Reversible registered work does not repeatedly interrupt the user.
- Financial, credential, privilege, unrecoverable, security, and materially
  broader public boundaries cannot be silently authorized.
- Useful explicit preferences and decisions become inspectable memory without
  retaining audio, secrets, file content, or unlimited transcript history.
- Memory can be edited, disabled, exported, and deleted.

## Hero business journey

- A configured provider can turn a business-website objective into a valid
  sequential multi-step plan.
- The plan creates a responsive website and supporting artifacts inside the
  selected approved Project without arbitrary filesystem or shell access.
- Morpheus verifies the produced project before reporting success.
- The user can open a real local preview and inspect generated files.
- Analytics readiness and a thirty-day management/content plan are real
  artifacts, not decorative claims.
- Follow-up reminders or schedules use Morpheus-owned durable services.
- Staging deployment is real when a supported destination is configured and is
  truthfully unavailable otherwise.
- No screen promises passive income or guaranteed business results.

## Experience

- The operator-first surface is visually coherent at 1280x800 and current
  desktop resolution.
- The original Morpheus identity, real state, objective, current work, result,
  artifact, and stop/redirect controls are immediately legible.
- The interface does not resemble a generic chat client, card dashboard, or
  cheap terminal skin.
- Reduced motion, keyboard use, screen-reader state labels, and Windows scaling
  remain functional.
- All new user-facing text has en, zh, ja, and ru coverage.

## Regression and delivery

- Existing capabilities, grants, Audit ordering, Missions, Projects, Goals,
  Systems, workflows, schedules, providers, OpenClaw Gateway, and Chat remain
  functional.
- Typecheck, lint, targeted unit tests, Morpheus E2E, routing/Gateway canaries,
  harness validation, communication replay, Vite build, Windows packaging, and
  packaged smoke have run.
- The installer is unsigned unless authorized production signing credentials
  are available; the report states that truthfully.
