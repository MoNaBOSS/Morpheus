# Morpheus 1.1.1 Provider and Voice Optimization candidate

## Purpose

This candidate removes two avoidable barriers from the 1.1.0 review build:
premium-model defaults and a voice service that excluded OpenRouter accounts.
It does not replace the Signal experience, Objective Core, OpenClaw runtime,
permissions, capabilities or audit architecture.

## Changes

- New OpenAI and OpenRouter accounts use the cost-aware Luna model by default.
- Existing provider models can be changed in place without deleting the account
  or re-entering its API key.
- OpenRouter setup exposes balanced and economy model choices.
- A configured OpenRouter account can power planning, transcription and speech.
- Voice Settings exposes an efficient Kokoro preset and a more expressive
  Orpheus preset, both using Whisper Large V3 Turbo for transcription.
- Speech voice choices follow the selected model family, preventing obviously
  incompatible voice IDs.
- Keys remain Main-owned and local; no shared production credential is bundled.

## Larry configuration

1. Open **Models**, add **OpenRouter**, enter the OpenRouter key, and keep the
   recommended `openai/gpt-5.6-luna` model. Use the Economy button when minimum
   model cost matters more than consistent planner quality.
2. Open **Settings -> Voice operator**.
3. Choose **Efficient - Kokoro** first. Use **Expressive - Orpheus** when voice
   character matters more than the lowest cost.
4. Run **Preview selected voice** and **Check microphone**. A configured account
   is not considered a successful voice test until these checks pass.
5. Enable **Ambient companion**. Leave local name detection off for the broadest
   hardware compatibility, or enable it when Windows English Speech Recognition
   is installed and the microphone works with the local recognizer.
6. Say “Morpheus”, pause for acknowledgement, then say the objective. The Signal
   shows listening, understanding, working and speaking from real runtime state.

## Truthful boundary

Credential-independent unit, Electron and packaging checks can verify request
shape, state transitions, UI, fallback and secret boundaries. They cannot prove
that a specific paid account is funded, entitled to a model, acoustically clear
on another computer, or billed correctly. Those items require Larry's real key,
microphone, speakers and provider usage page.

Authenticode remains credential-owned and is not simulated locally.
