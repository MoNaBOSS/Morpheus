# Morpheus 1.0.2: responsive operator

## Changes

- Main-owned planner limit: 48,000 input characters per request; 4,096 output
  tokens normally, 8,192 for English website objectives; at most six requests and
  32,768 reserved output tokens per selected planner instance (one objective).
  Failed requests consume allowance. Existing sequential execution, three
  iterations, native-action policy and timeout limits remain intact.
- Protocol-specific limits for OpenAI Completions/Responses, Anthropic, Gemini
  and Ollama. No uncapped fallback if an endpoint rejects a limit. Streamed
  transport responses bounded to 64 KiB. Aborted requests never start network work.
- Ambiguous network failures no longer automatically retry; explicit retryable
  HTTP errors retain the existing bounded retry. Started/completed usage records
  contain request identity, limits and validated provider-reported token counts,
  never prompts, keys, responses or file content. Missing usage stays missing.
- Speech cancellation aborts Main-side HTTP and invalidates pending preflight.
  A visible preparation state allows cancellation before playback. Push-to-talk
  interrupts speech before opening the mic. Metadata-only Mission changes no
  longer generate duplicate speech. Completed spoken summaries capped at 420
  characters; full results stay unchanged in the Mission.
- Ambient detection uses a 20Hz timer instead of requestAnimationFrame. Main
  disables background throttling only for an explicitly armed ambient session
  and restores it on stop. Hidden Signal animations pause independently.
- Luminous state-driven corona, settled completed strands, soft Mission entry,
  live voice priority and reduced-motion support. No pricing/subscription UI.

## Cost investigation and limits

The available local OpenClaw transcripts contained 16 usage-bearing messages
across three sessions, with 321,148 aggregate reported tokens and approximately
0.676161 in runtime-estimated cost units. These are not provider invoices, may be
incomplete or inaccurate, and do not establish the cause of the user's EUR80
charge. No secret or conversation content was exported for this investigation.

The new caps apply to Morpheus Core planning, not independent OpenClaw Chat tool
loops, other applications using the same key, or the provider's billing system.
They are not a euro cap. A provider usage export with timestamp/model/token totals
is needed to reconcile the charge. No website/planning requests were made to
diagnose it. Packaged voice verification attempted automatic greetings and one
short speech probe; the configured speech endpoint returned HTTP 401.

Cancelled providers can still bill already generated work. Voice remains
provider-dependent and ambient wake matching still happens after cloud
transcription; this is not an offline wake-word engine. Real microphone/accent
accuracy and paid voice quality require personal testing with configured services.
